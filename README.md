**ParaNMR** is an open-source Python toolkit for prediction, fitting, and analysis
of paramagnetic NMR spectra based on experimental data and ab initio calculations.

## Features

- Prediction of paramagnetic NMR shifts and spectra
- Susceptibility tensor fitting from experimental measurements
- Integration with quantum chemistry outputs (ORCA, Gaussian, Molcas)

## Installation

```bash
pip install paranmr
paranmr --help
```

ParaNMR requires Python 3.10 or newer. The supported baseline is verified in
CI on Python 3.10, 3.11, and 3.12.

### Synthetic GMM acceptance suite

Run the seeded GMM acceptance test against the committed fixture:

```bash
pytest tests/integration/synthetic
```

The fixture is generated by ParaNMR-Synth and committed with provenance, so
running this test does not require ParaNMR-Synth. The test remains opt-in in
CI while the GMM fitting engine is under active development.

## Quick example

```bash
paranmr predict input.yml
```
