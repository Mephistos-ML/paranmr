```SimpNMR``` is a python package for working paramagnetic nuclear magnetic resonance (pNMR) data.

These pages contain the documentation for the ``SimpNMR`` python package, and its associated command line interface.

New users
^^^^^^^^^

First visit :ref:`installation` to see how to set up ``SimpNMR``, then check out the :ref:`guide` pages for instructions on how to use ``SimpNMR``.
