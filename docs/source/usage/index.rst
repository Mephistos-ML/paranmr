There are two interfaces to ``SimpNMR``, which one you choose depends on the complexity of the data
you are processing, and your familiarity with using a command line/terminal application.

For most users, we recommend the command line interface to ``SimpNMR`` which surfaces a number of
advanced features, and allows fitting of suscpetibility and hyperfine tensors. The command line interface is included
in the installation of the ``SimpNMR`` package, see :ref:`Installation` for details.

More advanced users may be interested in using the the ``SimpNMR`` package in their own python code.
This functionality is documented within this manual, see :ref:`guide_scripting` and :ref:`modules`.
