Reporting Bugs
==============

Please check the :ref:`faq` page before reporting any bugs!

To report bugs with ``simple_pnmr`` please raise a `GitHub Issue <https://github.com/jonkragskow/simple_pnmr/issues>`_ instead
of emailing individual developers. We appreciate users reporting bugs, as this makes ``simple_pnmr``
better for everyone.

To make life easier for the person helping you, and to save time replicating the issue you're reporting,
we ask that you **use the issue template** as indicated on the create issue page, and provide the following
information.

Please first update ``simple_pnmr`` with ``pip install --upgrade simple_pnmr``

1. Versions of ``python`` and ``simple_pnmr``. Obtained with ``python --version`` and ``pip show simple_pnmr``
2. All input file(s)
3. All input commands used or minimal-working-example of code
4. Any (incorrect) output of ``simple_pnmr``
