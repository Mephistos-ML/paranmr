Reporting Bugs
==============

If you find a bug, please first update ``SimpNMR`` with ``pip install --upgrade simpnmr``

If the bug persists, then please check the :ref:`faq` page before reporting any bugs!

To report bugs with ``SimpNMR`` please raise a `GitLab Issue <https://gitlab.com/suturina-group/simpnmr/-/issues>`_ **instead
of emailing individual developers**. We appreciate users reporting bugs, as this makes ``SimpNMR``
better for everyone.

To make life easier for the person helping you, and to save time replicating the issue you're reporting,
we ask that you **use the issue template** as indicated on the create issue page, and provide the following
information.

1. Versions of ``python`` and ``SimpNMR``. Obtained with ``python --version`` and ``pip show simpnmr``
2. All input file(s)
3. All input commands used or minimal-working-example of code
4. Any (incorrect) output of ``SimpNMR``
