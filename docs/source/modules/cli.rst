Command Line Interface
======================


The command line interface to ``SimpNMR``.

This module provides the main entry point for SimpNMR’s command line tools.
It includes functions for parsing YAML configuration files, validating input,
and running the ``predict`` and ``fit_susc`` subprograms.

This page is currently under development, and more detailed documentation
of each subcommand and helper function will be added in future updates.
